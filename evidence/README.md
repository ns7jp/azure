# 証跡の残し方

`deployment-record.example.md` をコピーして使う。証跡は「実施した事実」を第三者が追跡できる記録であり、見栄えだけのスクリーンショットではない。

保存してよい例:

- コマンド（秘密情報を除く）
- UTC/JSTの実施日時
- 終了コード、期待値、実測、PASS/FAIL
- マスク済みの画面・ログ
- 失敗原因と再試験結果

保存してはいけない例:

- SSH秘密鍵、パスワード、アクセストークン
- 未マスクのテナントID・サブスクリプションID
- 実在顧客や個人の機密情報

証跡画像を追加する場合は `evidence/images/` を作り、意味の分かる名前（例 `ST-01-bicep-build-pass.png`）にする。
